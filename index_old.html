Cloud Concepts Six benefits of cloud, deployment models, well-architected framework

Six advantages of cloud: trade capex for opex · benefit from massive economies of scale · stop guessing capacity · increase speed & agility · stop spending on data centers · go global in minutes.

Deployment models: cloud · hybrid · on-prem. The Well-Architected Framework has 6 pillars — operational excellence, security, reliability, performance efficiency, cost optimization, sustainability.

📄 Download full PDF notes

Security Shared Responsibility, IAM, encryption, compliance

Shared responsibility: AWS handles security of the cloud (hardware, hypervisor, regions). Customer handles security in the cloud (data, IAM, OS patches, network rules).

IAM: users, groups, roles, policies. Policies are JSON. Always least-privilege; never use root for daily work; enable MFA.

📄 Download full PDF notes

Technology EC2, S3, VPC, RDS, Lambda, CloudFront

Core compute (EC2, Lambda, ECS/EKS, Fargate), storage (S3 classes, EBS, EFS, Glacier), networking (VPC, subnets, route tables, NAT, Direct Connect, Route 53), databases (RDS, DynamoDB, Redshift, Aurora).

📄 Download full PDF notes

Billing Pricing models, support plans, AWS Organizations

On-demand · reserved · savings plans · spot. Free tier limits. Support plans: Basic, Developer, Business, Enterprise On-Ramp, Enterprise. Cost Explorer, Budgets, AWS Pricing Calculator, Trusted Advisor.

Fundamentals AI vs ML vs Deep Learning vs Generative AI

AI is the umbrella — any system that mimics human intelligence. ML is a subset where systems learn from data. Deep Learning is ML using neural networks with many layers. Generative AI uses foundation models to create new content (text, images, code).

Key terms: training data, inference, model parameters, foundation model, fine-tuning, prompt engineering, embeddings, vector store, hallucination.

Generative AI Foundation models, tokens, embeddings

Foundation models are large pre-trained models (Claude, Titan, Llama, Mistral, Stable Diffusion) used as a base for many tasks. Tokens are chunks of text the model processes (~4 chars each in English).

Embeddings = vector representations of text/images that capture meaning. Used in semantic search and RAG.

Bedrock Amazon Bedrock service deep dive

Fully managed service for foundation models. Single API across multiple model providers. Features: Knowledge Bases (managed RAG), Agents, Guardrails, Model Evaluation, Fine-tuning, Provisioned Throughput.
